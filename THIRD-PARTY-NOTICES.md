# Third-party notices

Workspace Hub keeps third-party notices in the project and installs them with
the application. These notices concern bundled dashboard icon assets only; they
do not indicate telemetry, online services, or runtime dependencies.

## Fluent Icon Theme for Linux

Workspace Hub bundles a curated subset of unmodified SVG assets from the
Vinceliuice Fluent Icon Theme for the default **Fluent Linux Color** dashboard
style and the optional **Fluent Linux Grey** style. The files are renamed only
to give them a private Workspace Hub icon namespace.

Source project: `vinceliuice/Fluent-icon-theme`

Copyright belongs to the Fluent Icon Theme contributors.
Licensed under the GNU General Public License, version 3. The full license text
is included at:

`data/licenses/fluent-icon-theme-COPYING.txt`

The grey upstream variant primarily changes folder and network colours. App and
utility icons therefore remain coloured where the upstream grey variant uses
the same asset as the standard variant.

## Microsoft Fluent UI System Icons

Workspace Hub bundles a curated subset of colour SVG assets from Microsoft
