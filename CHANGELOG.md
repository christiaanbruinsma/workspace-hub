# Changelog

## 0.9.0 — 6 August 2026

Initial public beta baseline.

- Add independent workspaces with create, switch, rename, duplicate, reorder, archive, restore and guarded delete actions.
- Add guarded full-workspace content replacement with target identity preservation and an automatic pre-overwrite restorepoint.
- Add a context-aware reset for the active workspace that creates a restorepoint first and preserves its identity, appearance and every other workspace.
- Add a fresh independent example workspace at any time without changing existing workspaces.
- Add native section tabs for Apps, Web apps, Files & places and Daily tools.
- Add local application discovery for desktop entries, Flatpak, Snap and user launchers.
- Add native tile and dashboard context menus with keyboard access.
- Add live item moves between section tabs and validated copy or move actions between workspaces.
- Add portable workspace import and export with workspace-specific restorepoints and explicit version restore through Workspace History.
- Add English, Dutch and German primary interface support.
- Add local diagnostics with privacy redaction and no automatic remote probing.
- Add serialised library mutations, latest-value view-state persistence and fail-closed recovery for damaged or unwritable data.
- Add GNOME Builder Flatpak development support and reproducible native Debian packaging.
