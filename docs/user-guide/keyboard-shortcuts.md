# Keyboard shortcuts

| Shortcut | Destination |
|---|---|
| Ctrl+1 | Overview |
| Ctrl+2 | Apps |
| Ctrl+3 | Web apps |
| Ctrl+4 | Files & places |
| Ctrl+5 | Daily tools |
| Ctrl+6 | Help & support |
| Ctrl+7 | Workspace status |
| Ctrl+8 | Settings |
| Shift+F10 | Open the context menu for the focused dashboard tile or active section tab |
| Menu key | Open the context menu for the focused dashboard tile or active section tab |

Standard GTK keyboard navigation remains available for moving focus, activating controls and closing dialogs. On configured-item rows, move focus to the `⋮` action button and press Enter or Space to open Edit, Move to Tab, ordering and removal actions. Section-tab menus apply to the active tab. The dashboard background menu is pointer-contextual; all of its actions remain available through the visible collection pages and Settings.
